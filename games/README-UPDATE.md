# Cossert Game Arcade Update

This package updates only the `games` area.

It keeps links to the five existing classic games and adds five new games:
- Cossert Dash
- Syntax Invaders
- Neon Snake
- List Labyrinth
- Random Roulette

Upload/replace `games/index.html` and `games/style.css`, then add the five new HTML files. Keep the existing classic game files already in your repository.

Your root `index.html` already links to `./games/`, so the root page does not need to change.
