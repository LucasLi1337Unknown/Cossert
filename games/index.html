Game Arcade

← Center

Five small browser games built around Cossert ideas. They are games about the language; they do not define new official syntax.

1. Keyword Catch

Click only real preserved Cossert keywords before time runs out.

2. Stable Slot Memory

Remember which list slot was removed without shifting IDs.

3. Random Exclusion

Predict whether a random result is valid under W/O(...).

4. Loop Runner

Use SKIPTIS and FRGETABTIT at the right moment.

5. Syntax Match

Match Cossert forms with what they mean.
