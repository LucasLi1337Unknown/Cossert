# Building a Language Playground

This guide is part of the Cossert 0.2 Center.

## Rule

Preserve official syntax exactly. Unknown full-0.2 behavior must stay marked `0.2 TODO`.

## Checklist

- Is the syntax official?
- Is there a matching example?
- Is there a matching test?
- Does it preserve stable list IDs and the known control/return/random rules?
