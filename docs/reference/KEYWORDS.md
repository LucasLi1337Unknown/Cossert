# Keyword Quick Reference

| Keyword | Meaning | Category |
|---|---|---|
| `SKIPTIS` | Skip current loop iteration | loop |
| `FRGETABTIT` | Exit current loop | loop |
| `FINALANSER` | Return function result | function |
| `PICKARANDOM` | Random choice from domain | random |
| `FROM` | Start/domain marker | random helper |
| `TO` | End/domain marker | random helper |
| `W/O` | Exclude a value | random helper |
| `HAV A LIST` | Declare named list | list |
| `TAKITOUT` | Remove while preserving slot IDs | list |
